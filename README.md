# ☀️ UK Residential Solar ROI & Battery Payback Calculator

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Netlify-00C7B7?style=for-the-badge&logo=netlify&logoColor=white)](https://splendorous-swan-27a3f2.netlify.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

An interactive solar energy calculation widget built for clean energy installers and green technology websites in the UK.

## ⚡ Key Features
- **Dynamic System Sizing:** Sizing algorithms based on monthly electricity consumption and roof orientation.
- **Payback & ROI Engine:** Real-time 25-year cumulative savings chart and break-even timeline modeling.
- **Battery Storage Logic:** Optional battery storage configuration factoring in peak/off-peak tariffs.
- **Lead Routing:** Instant dispatch to WhatsApp or email sales channels.
